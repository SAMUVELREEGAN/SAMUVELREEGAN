# Samuvel Reegan — Portfolio

Personal portfolio site for **Samuvel Reegan**, Full-Stack Developer (React, React Native, Node.js).

## Live site

[https://samuvelreegan.vercel.app](https://samuvelreegan.vercel.app)

## Features

- Light / dark mode
- Responsive layout with mobile bottom navigation
- Editorial projects gallery with scroll animations
- Contact form (FormSubmit — frontend only)
- Open-source playground section

## Development

```bash
npm install
npm start
```

## Build & deploy

```bash
npm run build
npx vercel deploy build --prod --yes --project samuvelreegan
```
